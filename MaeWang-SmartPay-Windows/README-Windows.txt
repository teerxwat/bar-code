========================================================
  MaeWang SmartPay — Print Station (Windows)
  คู่มือติดตั้งและใช้งานบนเครื่อง Windows ที่ต่อเครื่องปริ้นบาร์โค้ด TSC
========================================================

ไฟล์ในชุดนี้
------------------------------------------------
  MaeWang-SmartPay.exe      ← ดับเบิลคลิกเพื่อใช้งานประจำวัน (สตาร์ท server + เปิดเว็บ)
  run-print-server.bat      ← ตัวสตาร์ท print server (exe เรียกให้อัตโนมัติ)
  setup.bat                 ← ลง library ครั้งเดียวตอนติดตั้ง
  tsc_te310_print_server.py ← โปรแกรม print server
  NotoSansThai-Variable.ttf ← ฟอนต์ไทย (ต้องอยู่โฟลเดอร์เดียวกัน ห้ามลบ)

*** ไฟล์ทั้งหมดต้องอยู่ในโฟลเดอร์เดียวกันเสมอ ***


วิธีทำงาน (ภาพรวม)
------------------------------------------------
เว็บแอป SmartPay (บนเบราว์เซอร์) จะส่งคำสั่งพิมพ์มาที่ print server ที่รันอยู่บน
เครื่องเดียวกัน (http://localhost:9100) แล้ว server ยิงข้อมูลไปเครื่องปริ้น TSC
ผ่าน USB โดยตรง ดังนั้นเครื่องนี้ต้องเปิด print server ค้างไว้ตอนใช้งาน


========================================================
  ติดตั้งครั้งแรก (ทำครั้งเดียวต่อเครื่อง)
========================================================

ข้อ 1) ติดตั้ง Python 3
------------------------------------------------
  - ดาวน์โหลด: https://www.python.org/downloads/windows/
  - ตอนติดตั้ง **ติ๊กช่อง "Add Python to PATH"** ให้เรียบร้อย (สำคัญมาก)

ข้อ 2) ลง library ที่ต้องใช้
------------------------------------------------
  - ดับเบิลคลิก  setup.bat  แล้วรอจนขึ้น "เสร็จแล้ว!"
    (มันจะลง pyusb, pillow, libusb-package ให้อัตโนมัติ)

ข้อ 3) ลงไดรเวอร์ USB ของเครื่องปริ้นด้วย Zadig  ← ขั้นตอนที่คนมักลืม
------------------------------------------------
  Windows คุยกับเครื่องปริ้น TSC ผ่าน USB แบบ raw ไม่ได้ถ้าไม่เปลี่ยนไดรเวอร์เป็น
  WinUSB ก่อน (ต่างจาก Mac ที่ใช้ได้เลย)

  - ดาวน์โหลด Zadig: https://zadig.akeo.ie/
  - เสียบเครื่องปริ้น TSC แล้วเปิดเครื่องปริ้น
  - เปิด Zadig → เมนู Options → ติ๊ก "List All Devices"
  - เลือกเครื่องปริ้น TSC (เช่น "TSC TE310" หรือชื่อที่มี TSC) จาก dropdown
  - ช่องไดรเวอร์เป้าหมายเลือก **WinUSB** แล้วกด "Replace Driver"
  - รอจนเสร็จ (ประมาณ 10-30 วินาที)

  หมายเหตุ: หลังทำขั้นนี้ เครื่องปริ้นตัวนี้จะพิมพ์ผ่านระบบพิมพ์ปกติของ Windows
  ไม่ได้แล้ว (ตั้งใจให้เป็นแบบนั้น เพราะเราคุย USB ตรงผ่าน server)
  ถ้าจะกลับไปใช้ไดรเวอร์เดิม ใช้ Device Manager → Uninstall แล้วเสียบใหม่


========================================================
  ใช้งานประจำวัน
========================================================
  1) ดับเบิลคลิก  MaeWang-SmartPay.exe
       → จะมีหน้าต่างดำ (print server) เด้งขึ้นมา = server กำลังทำงาน
       → เบราว์เซอร์จะเปิดหน้า login ให้อัตโนมัติ
  2) ทำงานสแกน/พิมพ์บาร์โค้ดตามปกติ
  3) เลิกงาน: ปิดหน้าต่างดำ (print server) = หยุด server
       (จะปิดเว็บด้วยหรือไม่ก็ได้)


========================================================
  กรณีมีเครื่องปริ้นหลายตัวต่อคอมเดียว (เอกสาร + บาร์โค้ด)
========================================================
  โดยปกติ server จะเลือกเครื่องที่ชื่อมี "TSC" ให้เอง และข้ามเครื่องเอกสาร
  ถ้าอยากล็อกให้ชัวร์ว่าออกเครื่องบาร์โค้ดตัวไหน:

  1) หา VID/PID ของเครื่องบาร์โค้ด — เปิด Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์:
        python tsc_te310_print_server.py --list
     จะเห็นรายการอุปกรณ์ USB พร้อม VID=... PID=... และ tag [printer]

  2) ตั้งค่าให้ exe ล็อกเครื่องนั้น — สร้างไฟล์ start.bat ในโฟลเดอร์นี้ เนื้อหา:
        @echo off
        cd /d "%~dp0"
        set TSC_VID=0x1203
        set TSC_PID=0x0230
        python tsc_te310_print_server.py
     (เปลี่ยนเลข VID/PID เป็นของเครื่องคุณจากข้อ 1)
     แล้วใช้ start.bat แทน หรือแจ้งผู้ดูแลให้ปรับ exe ให้เรียก start.bat


========================================================
  แก้ปัญหาที่พบบ่อย
========================================================
  - เปิด exe แล้วหน้าต่างดำขึ้น [ERROR] ไม่พบ Python
      → ยังไม่ได้ลง Python หรือลืมติ๊ก "Add Python to PATH" (ทำข้อ 1 ใหม่)

  - server ขึ้น "หา TSC ไม่เจอ" / USB error
      → ยังไม่ได้ทำ Zadig (ข้อ 3) หรือเครื่องปริ้นยังไม่เปิด/สาย USB หลุด

  - เว็บกดพิมพ์แล้วไม่ออก
      → เช็คว่าหน้าต่างดำ (print server) ยังเปิดอยู่ไหม, ต้องเปิดค้างตลอดการใช้งาน

  - พิมพ์ออกแต่ภาษาไทยหาย
      → ไฟล์ NotoSansThai-Variable.ttf ต้องอยู่โฟลเดอร์เดียวกับ .py
