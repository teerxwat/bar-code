========================================================
  MaeWang SmartPay - Print Server (Windows)
  คู่มือหลังติดตั้ง
========================================================

แอปนี้คือ print server ที่รับคำสั่งพิมพ์จากเว็บแอป SmartPay (http://localhost:9100)
แล้วส่งไปเครื่องปริ้นบาร์โค้ด TSC ผ่าน USB โดยตรง ไม่ต้องลง Python เอง


ทำครั้งเดียวต่อเครื่อง: ลงไดรเวอร์ USB ด้วย Zadig
------------------------------------------------
  Windows คุยกับเครื่องปริ้น TSC ผ่าน USB ตรงๆ ไม่ได้ ถ้ายังไม่เปลี่ยนไดรเวอร์เป็น WinUSB

  1) ดาวน์โหลด Zadig: https://zadig.akeo.ie/
  2) เสียบสาย USB แล้วเปิดเครื่องปริ้น TSC
  3) เปิด Zadig > เมนู Options > ติ๊ก "List All Devices"
  4) เลือกเครื่องปริ้น TSC จาก dropdown
  5) ช่องไดรเวอร์เป้าหมายเลือก WinUSB แล้วกด "Replace Driver" รอจนเสร็จ

  หมายเหตุ: หลังทำขั้นนี้ เครื่องปริ้นตัวนี้จะพิมพ์ผ่านระบบพิมพ์ปกติของ Windows ไม่ได้
  ถ้าจะกลับไปใช้ไดรเวอร์เดิม: Device Manager > Uninstall device แล้วเสียบใหม่


ใช้งานประจำวัน
------------------------------------------------
  1) เปิด "MaeWang SmartPay" จาก Start Menu หรือไอคอนบน Desktop
       - หน้าต่างดำ (print server) จะขึ้นมา = server กำลังทำงาน
       - เบราว์เซอร์จะเปิดหน้า login ให้อัตโนมัติ
  2) ใช้งานเว็บแอป กดพิมพ์ตามปกติ (ต้องเปิดหน้าต่างดำค้างไว้ตลอด)
  3) เลิกงาน: ปิดหน้าต่างดำ = หยุด server


อัปเดตเวอร์ชันใหม่
------------------------------------------------
  ตอนเปิดแอป ถ้ามีเวอร์ชันใหม่จะมีหน้าต่างถาม "อัปเดตเลยไหม?" กด Yes แล้วรอสักครู่
  แอปจะปิด ติดตั้ง แล้วเปิดใหม่เอง (กด No = ใช้เวอร์ชันเดิมต่อ แล้วถามใหม่รอบหน้า)
  หรือรันตัวติดตั้งเวอร์ชันใหม่ทับเองก็ได้ ไม่ต้องถอนของเก่า ไฟล์ .env ที่ตั้งค่าไว้จะยังอยู่


ตั้งค่าเพิ่มเติม (ไม่บังคับ)
------------------------------------------------
  โฟลเดอร์ติดตั้ง: %LOCALAPPDATA%\Programs\MaeWang SmartPay
  ก๊อปไฟล์ .env.example ในโฟลเดอร์นั้นเป็นชื่อ .env แล้วใส่ค่าที่ต้องการ เช่น
      SMARTPAY_PRINT_KEY=...     (ปกติไม่ต้องใส่ ตัวติดตั้งใส่มาให้แล้วใน default.env)
      TSC_VID=0x1203             (ล็อกเครื่องปริ้น กรณีต่อ TSC หลายตัว)
      TSC_PID=0x0230
      TSC_MOCK=1                 (โหมดทดสอบ ไม่พิมพ์จริง เซฟรูปไว้ที่ previews\)
  แล้วปิด-เปิดแอปใหม่

  ดู VID/PID ของเครื่องปริ้น: เปิด Command Prompt ในโฟลเดอร์ติดตั้ง แล้วพิมพ์
      MaeWang-SmartPay.exe --list


แก้ปัญหาที่พบบ่อย
------------------------------------------------
  - Windows ขึ้น "Windows protected your PC" ตอนติดตั้ง
      > กด "More info" แล้ว "Run anyway" (แอปยังไม่ได้เซ็นรับรอง)
  - server ขึ้น "หา TSC ไม่เจอ" / USB error
      > ยังไม่ได้ทำ Zadig หรือเครื่องปริ้นยังไม่เปิด / สาย USB หลุด
  - เว็บกดพิมพ์แล้วไม่ออก
      > เช็คว่าหน้าต่างดำ (print server) ยังเปิดอยู่
  - สระ/วรรณยุกต์ภาษาไทยวางเพี้ยน
      > แจ้งผู้ดูแลระบบ (ต้องเพิ่ม fribidi.dll ให้ Pillow ใช้ RAQM ได้)
